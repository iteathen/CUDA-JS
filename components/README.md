# Components

Production LEGO components are created only after their contracts and predecessor experiments pass.

Planned owners are defined in the target architecture and focus map: platform/capability resolver, schema compiler, private Node FFI adapter, DriverActor/resource core, memory, module/launch/completion, CompilerActor/toolchain/cache, errors/health, safe facade, diagnostics, and packaging.

The first code remains experiment-owned; do not create empty production component scaffolding merely to mirror the plan.
