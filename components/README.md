# Components

Production LEGO components are created only after their contracts and predecessor experiments pass.

Implemented internal owners are [`driver-actor/`](driver-actor/README.md) and [`resource-registry/`](resource-registry/README.md) under accepted SPEC-0003. Later owners remain defined in the target architecture and focus map: platform/capability resolver, memory, module/launch/completion, CompilerActor/toolchain/cache, broader errors/health, safe facade, diagnostics, and packaging.

The first code remains experiment-owned; do not create empty production component scaffolding merely to mirror the plan.
