# Reusable Engineering Foundation

These documents adapt the shared engineering doctrine used across the owner's large projects to CUDA-JS. They are project-neutral where possible and subordinate to root `AGENTS.md`, accepted CUDA-JS ADRs/specifications, and explicit current owner instruction.

Read selectively: load the instruction chain and every objectively triggered doctrine file, but do not reread the full directory for routine work. [`NO_PYTHON_POLICY.md`](NO_PYTHON_POLICY.md) is an accepted ecosystem-wide hard gate and is always applicable when a task can affect language, dependencies, tooling, build, tests, generators, CI, packaging, experiments, or repository topology.
