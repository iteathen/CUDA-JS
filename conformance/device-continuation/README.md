# Device continuation candidate conformance

The [owner-authorized candidate](../../docs/specs/SPEC-0020-device-continuation-addendum.md)
has CUDA-free frontend checks and public finite physical capsules. Maintained
authoring is JavaScript/Device-JS; graph ABI facts come from compiler parsing of
the pinned NVIDIA header. No C/C++ probe or project-specific native addon is used.

Run the `.mjs` capsules using the exact selected Node executable. Physical capsules
require `--experimental-ffi`, the admitted Windows x64 CUDA 13.3 providers and a
compatible physical GPU. `device-continuation-public-native-20261008.mjs` accepts
`--rounds=8` through a finite `--rounds=8000000`; its wait policy is 60 seconds.
Every body/controller kernel is bounded. No watchdog/registry changes are made.

The counter/sum oracle is independent integer arithmetic. Lower-owned mechanism
counts verify one external launch; opaque mailbox capsules verify leased
publication/cooperative stop. These are candidate evidence, not general duration,
platform, security, performance or support qualification. Exact revision, package
and runtime identities belong in the external evidence record after source freeze.
