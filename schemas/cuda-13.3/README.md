# CUDA 13.3 schema facts

This directory contains the pinned CUDA 13.3 source/provenance and generated schema products used by CUDA-JS. It is an index, not an independent ABI or support authority.

- [`provenance.json`](provenance.json) records the pinned official-source provenance and selection identity.
- [`linux-x64/`](linux-x64/) contains Linux x64 generated products.
- [`win-x64/`](win-x64/) contains Windows x64 generated products.
- [`tier-0/`](tier-0/) contains reviewed Tier-0 semantic overlay/material.

The governing import/generation contracts, component ownership, compatibility state and qualification limits remain in their existing CUDA-JS specifications, component documents, compatibility manifests and conformance evidence.
