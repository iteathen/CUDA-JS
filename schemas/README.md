# Schemas

Versioned generated CUDA ABI facts, curated semantic overlays, normalized Runtime IR, generated Node FFI definitions/packers/types/tests/manifests, provenance, and compatibility records.

No schema implementation is authorized in the current documentation-only phase. When the project owner advances the phase, the first eligible work is the synthetic ABI schema/harness required by EXP-000 and the Tier-0 importer/overlay/layout-probe subset required by EXP-001 through EXP-003. New or changed official declarations remain unavailable until semantic and native-layout gates pass.
