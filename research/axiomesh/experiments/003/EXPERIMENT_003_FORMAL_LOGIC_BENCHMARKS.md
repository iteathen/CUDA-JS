## Purpose

Experiment 003 pressures AxiomeSH across formal systems whose source notations and proof rules differ materially.

The experiment is now explicitly testing two coupled claims:

1. formal knowledge can be represented/reasoned over natively without hidden host semantics;
2. independent domains can expose true common structural classes/isomorphisms without labels or representation choices manufacturing the answer.

Syntax coverage alone is not success.

## Structural-class policy

Candidate labels C1–C12 / `^9101..^9112` remain navigation hypotheses only.

A reusable class is an immutable/versioned schema graph plus structured parameters, ports, positive/negative constraints, relation signature, factorization dependencies, residual policy, and qualification evidence.

Class membership requires an independently verified witness.

Known-class recognition and new-class induction are separate workflows.

The class registry is forbidden as blind discovery authority for its own mappings.

## Discovery policy

Candidate generation is part of correctness.

A corpus-scale run reports:

- eligible extraction universe;
- factorization/extraction coverage;
- index/fingerprint policies;
- learned-index training/supervision provenance if applicable;
- candidate pairs emitted;
- pairwise searches/verifications;
- hidden-label known-positive recall;
- negative/precision controls;
- resource limits/unsearched regions.

Fingerprint mismatches prune safely only when the fingerprint is a qualified necessary invariant for the exact frozen layer/view/relation target.

Approximate scores are retrieval metadata, not structural evidence.
