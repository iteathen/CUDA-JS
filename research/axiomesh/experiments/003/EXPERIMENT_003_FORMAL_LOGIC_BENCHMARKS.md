# Experiment 003 — Cross-Logic Proof Benchmark Campaign

**Branch:** `experiment/axiomesh-native-reconstruction`  
**Candidate spec lineage:** Draft 0.5 → 0.6 → 0.7 → 0.8 → 0.9 → 0.10 → 0.11 → 0.12  
**Status:** benchmark corpus/scaffold constructed; primitive decomposition, structural discovery, comparison verification, and class qualification are mandatory before proof claims

## Purpose

Experiment 003 tests AxiomeSH across 18 formal-logic benchmark families while using the suite to pressure the representation itself.

The target is not syntax coverage. It is a representation/discovery system in which independently named objects expose their common structural form without erasing the distinctions that make near-isomorphs different.

## Governing pipeline

```text
source semantics
-> qualified/versioned factorization set
-> qualified substructure candidates
-> label-blind structural indexing/retrieval
-> N0/N1 normalization
-> frozen comparison policy
-> structural search
-> candidate witness/certificate
-> independent witness verification
-> relation/common-core/residual result
-> versioned structural-class recognition
-> retained labels
-> explicit proof profile
-> proof/counterresult
-> independent proof review
```

For every benchmark:

```text
statement representation
!= semantic construction
!= discovery/index result
!= structural-class relationship
!= proof profile
!= proof
!= reviewed proof
```

## Qualification gates

### E0 — source fidelity
Preserve supplied theorem/premises/domain/test intent without silent repair.

### E1 — native statement expressibility
Represent supplied load-bearing statement distinctions natively. The historical `FORMAL_LOGIC_BENCHMARKS_003.axh` is primarily this scaffold.

### E1P — primitive semantic decomposition
Ground conventional derived operators in native construction plus justified primitive/model leaves.

### E1A — alias/factorization expansion
Retained aliases must reach qualified lower constructions; uniqueness is not assumed.

### E1C — structural-class classification
Classify only after structural evidence and a verified membership witness.

### E1E — class/instance expansion
Retained class/domain labels expand through versioned schemas/factorizations with residuals/ports preserved.

### E1N — normalization-layer audit
Keep N0/N1 representation normalization separate from D definitions and E theorem/profile equivalence.

### E1F — factorization audit
Preserve materially distinct qualified factorizations or report dependence/incompleteness.

### E1W — witnessed structural comparison
Every structural relationship carries mappings/correspondences, boundaries, parameters, constraints, common core, residuals, relation kind, and factorization assumptions.

### E1B — boundary/composition audit
Test ports, gluing, compatibility, and joint realizability.

### E1L — label-blind audit
Hide/permute non-evidential labels; the structural result must survive.

### E1M — mapping multiplicity audit
Preserve materially distinct witnesses/maximal cores unless a verified automorphism/equivalence quotient makes them irrelevant.

### E1Q — comparison-policy freeze audit
Freeze target layer, view/role rules, D/E authorities, factorization bounds, relation signature, and objective before expected mappings/results are unblinded.

### E1D — decomposition exactness/recursion audit
Exact semantic D edges round-trip from decomposed structure; recursive definitions expose base/step/fixed-point authority.

### E1S — symbol/bundle namespace audit
Stable semantic and structural identities cannot collide across independent namespaces; bundle partitioning must preserve namespace/binding/activation/boundary semantics.

### E1V — independent witness/certificate verification
Discovery and verification are separate.

### E1T — target-layer/conclusion-scope audit
Do not promote representation/schema similarity into source-theory semantic equivalence without a qualified bridge.

### E1R — retrieval/discovery coverage audit
Candidate generation is part of correctness. Report policy-relative recall, index semantics, and corpus coverage.

### E1U — class non-vacuity/selectivity audit
A reusable schema must impose a nontrivial shared structural relation and reject meaningful held-out near misses.

### E1X — extraction/context audit
Substructure extraction is a witnessed transformation with explicit cut/context residuals and extraction kind.

### E1H — held-out discovery-policy audit
Test retrieval/comparison policy families on structures not used to design their rules/classes.

### E1I — identity/reference/variable ownership audit
Verify structural namespaces, reference-preserved sharing, and variable ownership roles.

### E1K — index-invariant/search-engine audit
Verify view-specific invariant claims plus search soundness/completeness/heuristic metadata.

### E1COV — decomposition/common-core coverage audit
Report undecomposed residuals and account for every common/residual/boundary/excluded item.

### E1ISO — information-flow isolation audit
Use enforceable fresh-context isolation for discovery/verifier stages and record accessible resources.

### E2 — cold reconstruction
A fresh decoder reconstructs the statement bundle under the permitted historical/current specification boundary. E2 does not imply E1* structural qualification.

### E3 — proof-profile completeness
Supply complete native semantic/proof authority and exact dependency revisions.

### E4 — proof execution
Produce a proof/countermodel/consistency/non-derivability certificate or honestly scoped no-result/resource disposition.

### E5 — independent proof review
Independently check every proof/certificate step and dependency.

### Draft 0.12
Fourth-pass edge-case corrections:

- bare structural identities are namespaced across independent documents/bundles;
- reference resolution preserves structural sharing rather than performing naïve textual copies;
- every `?n` occurrence has a reconstructable owner/role;
- fingerprint mismatch pruning requires a verified relation/view-specific invariant, not vague “completeness/injectivity”;
- non-vacuity is based on nontrivial reusable constraints, not parameter byte share;
- round-trip fidelity is separated from semantic-decomposition coverage/undecomposed residuals;
- blind structural discovery requires enforceable fresh-context information isolation;
- retrieval recall and index qualification are policy/view relative;
- substructure extraction distinguishes induced versus lossy/projected forms;
- common-core witnesses classify every included/residual/boundary/excluded item;
- strong embedding reflects a relation signature frozen before the match;
- search engines declare soundness/completeness/heuristic behavior;
- approximate retrieval scores remain non-semantic;
- inferred class labels retain qualification provenance and multiple memberships may coexist;
- qualification includes structurally novel classes absent from the registry.

## Success condition

Experiment 003 does not pass because formulas parse, labels look right, or candidate pairs are easy to retrieve.

```text
18 source-faithful problems
-> native reconstruction
-> semantic decomposition
-> versioned factorization preservation
-> structurally qualified candidate retrieval
-> frozen-policy blind comparison
-> independently verified mappings/certificates
-> complete common-core/residual accounting
-> versioned non-vacuous class recognition

-> independent review
```

The structural question is:

> Can AxiomeSH find and verify the strongest justified cross-domain correspondence without names, namespaces, extraction choices, parameter choices, factorization choices, search limits, or hidden knowledge deciding the answer?
