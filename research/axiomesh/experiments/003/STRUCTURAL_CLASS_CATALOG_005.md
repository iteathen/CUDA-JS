# Family F1 — Evaluation over a generated region

Candidate common construction:

```text
origin
+ structured generator/relation
+ generated-region membership
+ body/property
+ evaluation mode/cardinality condition
+ satisfaction/evaluation contract
-> result
```

Structured parameters/ports may include origin, generator substructure, body structure, evaluation relation/profile, cardinality/selection mode, boundary policy, and visited-domain constraints.

Non-vacuity requires the fixed schema to constrain the relationship among those parameters rather than merely forwarding them.

## C1 — universal evaluation

Candidate instances:

- epistemic knowledge over an agent accessibility image;
- LTL `G` over a reflexive future region;
- CTL `AG` after explicit branching/path generation;
- universal quantification with explicit domain/generator and binder ownership.

Mapping independent generators into one slot yields parametric structural correspondence, not semantic identity of those generators.

## C2 — existential evaluation

Candidate instances:

- LTL `F`;
- CTL `EF` after branching reachability is explicit;
- existential quantification over explicit domain;
- target-predicate reachability.

## C3 — immediate-successor evaluation

Candidate specialization in which the generated region is the applicable immediate-successor image and its selection/cardinality semantics are explicit.

Nondeterministic next may instead be C1/C2 over a successor set.

C1–C3 remain candidate specializations of F1 until schema-level class-class witnesses verify that factorization.

# C4 — Finite path / reflexive-transitive closure

Candidate construction:

```text

+ endpoint/adjacency invariants
-> finite path witness / reachable endpoint
```

Candidate uses:

- common-knowledge reachability;
- reduction closure;

The one-step relation remains structured and load-bearing. Recursive/fixed-point authority is explicit.

# C5 — Predicate-selected induced restriction

Public announcement is a composition of restriction plus pre/post satisfaction; it is not exhausted by C5.

Dropping an included relation among retained objects is projection loss, not ordinary residual.

# C6 — Disjoint decomposition / recomposition

Candidate construction:

```text
whole resource
-> compatible/disjoint parts
-> recomposition = whole
-> subproperties on parts
```

Separating conjunction is a candidate instance when the full heap/resource semantics matches.

Ordinary conjunction, mere co-presence, or arbitrary graph composition are negative controls.

# Multiple memberships and new-class induction

One object may carry several verified memberships under different target layers/views/factorizations. Preserve each with its witness.

A structurally novel object need not be forced into C1–C12.

New-class workflow:

```text
verified structural evidence
-> NEW_CANDIDATE_CLASS schema induction
-> freeze candidate revision
-> held-out positive/negative validation
-> possible promotion
```

# Promotion requirements

A reusable class requires:

- immutable/versioned native schema satisfying `STRUCTURAL_CLASS_SCHEMA_CONTRACT_005.md`;
- qualified decomposition/profile dependencies;
- non-vacuity/selectivity evidence;
- at least two independent verified instances or an independently specified schema with held-out validation;
- blind structural retrieval of hidden-label positives;
- near-isomorphic, boundary, namespace, parameter-abuse, policy-leak, alternative-factorization, automorphism, occurrence, and search-negative controls;
- independent membership-witness verification;
- class-class witnesses for hierarchy/factorization claims;
- no circular use of target class membership to produce its own evidence;
- no simpler qualified factorization explaining the same structure without loss.

Until then this remains a hypothesis catalog, not an ontology.
