# CUDA-JS Sponsorship

**Status:** Informational

## Selected funding path

CUDA-JS uses **GitHub Sponsors** as its only repository funding link. This avoids a separate storefront, donation platform, payment integration, reward system, or project-managed billing database. Sponsorships support GitHub account costs, CI, CUDA testing hardware, qualified runner access, documentation, and maintenance.

GitHub Sponsors pays the sponsored account through its configured payout route; it does not automatically credit the maintainer's GitHub subscription invoice. The maintainer may use the payout to cover those project costs.

## One-time account-owner setup

Repository configuration is complete in [`.github/FUNDING.yml`](../.github/FUNDING.yml). The `iteathen` account owner must complete [GitHub's one-time personal Sponsors onboarding](https://docs.github.com/en/sponsors/receiving-sponsorships-through-github-sponsors/setting-up-github-sponsors-for-your-personal-account):

1. open <https://github.com/sponsors> and choose **Get sponsored** for `iteathen`;
2. complete the short profile, payout/bank or fiscal-host route, tax form, and two-factor-authentication requirement;
3. request GitHub approval;
4. after approval, publish the profile and optionally feature `iteathen/CUDA-JS`.

No repository change is required after approval; the existing funding configuration will point the Sponsor button at <https://github.com/sponsors/iteathen>.

## Copy-ready profile text

**Short bio**

> Building CUDA-JS: a capability-safe, Worker-owned Node.js runtime for CUDA Driver, NVRTC, and nvJitLink workflows.

**Introduction**

> CUDA-JS is an open-source, pre-release effort to make bounded CUDA compilation and execution accessible from Node.js without exposing raw native capabilities. Sponsorships help cover GitHub, CI, qualified Linux and Windows testing, CUDA hardware, documentation, and maintenance. Sponsorship does not buy roadmap control, support guarantees, or privileged security handling.

**Goal**

> Cover recurring GitHub and project-infrastructure costs, then expand independent Windows and Linux qualification.

For minimal maintenance, use at most two no-reward tiers:

- **Supporter — $5/month:** helps cover recurring project costs; no promised reward beyond thanks.
- **One-time thanks — $25 once:** supports testing and maintenance; no promised reward.

Do not promise support response times, feature priority, private builds, commercial rights, or advisory access through sponsorship tiers. Those require a separate written agreement where applicable.
